# Contacts App (Android)

## Overview
Contacts App is an Android application developed as part of my university assignment.  
The application allows users to store and view contact information locally using a modern Android architecture.

## Features
- Display a list of contacts
- Add new contacts
- Local data storage using Room 
- Reactive UI updates using ViewModel
- Clean and simple user interface

## Technologies Used
- **Kotlin**
- **Android SDK**
- **Room Database**


# It has the potential to be more fullfiled in the future by adding features like delete or edit a contact or even maybe adding a picture to a person.
